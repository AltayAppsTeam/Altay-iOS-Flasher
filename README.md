# Altay-Signed-iOS-Flasher
Altay Signed iOS Flasher uygulaması deposu
Bu bir imzası hala açık duran iOS sürümlerini eski iPhone'lara yüklemek için uygulamadır.
Yükleyeceğiniz sürümün iPhone'a yüklenecek olan sürümün hala resmi imzası duruyor olmalıdır aksi takdirde yüklemeyi deneseniz bile telefon o sürümde açılmaz ve iTunes'a düşer bu yüzden iPhone'a yükleyeceğiniz sürümün hala imzasının kaldırılıp kaldırılmadığına internetten bakmayı unutmayın mesela örnek vermek gerekirse: iPhone 5 telefonuna sadece iOS 8.4.1, iOS 10.3.3 ve iOS 10.3.4 yükleyebilirsiniz.
Program kişisel amaçlı ve zevk amacıyla tasarlanmıştır yapılırken yapay zekadan destek alınmaktadır hatalar olabilir.
Hem Windows hemde Linux versiyonu bulunur program ana versiyon olarak Linux için tasarlanmıştır fakat Windows'ta da çalıştırabilirisniz

1- (Linux-APT)
Öncelikle python kurun, nasıl mı? Terminal'e aşağıdaki komutu yazarak python kurabilirsiniz

sudo apt install python3

Python'ı kurduktan sonra Altay Signed iOS Flasher'ın linux için olan python versiyonunu  indirin yani şu dosya
